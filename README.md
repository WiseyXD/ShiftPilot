# ShiftPilot

This project is an AI-powered staff scheduling web application designed for cafes and restaurants to automate weekly shift planning and communication. Managers can generate schedules in one click, automatically notify employees via email, and handle shift changes through natural language replies. The system intelligently understands employee responses (like unavailability) and automatically reschedules shifts, reducing manual coordination and saving hours of effort each week.

## MVP Features

* One-click weekly schedule generation based on employee availability
* Simple employee management (name, email, availability)
* Clean weekly schedule view (days × shifts)
* Automated email notifications for assigned shifts
* Natural language reply parsing (e.g., “I can’t work Friday”)
* Automatic shift reassignment when employees decline shifts
* Manager command input (e.g., “Fix Friday shift”)
* Real-time notifications for schedule changes
* Basic fairness logic for balanced shift distribution
